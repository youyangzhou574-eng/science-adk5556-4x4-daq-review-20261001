# 待测4×4电阻阵列如何接入

用户在本包问：PCB是否缺排线接口、待测电阻怎么接。现有J2是普通2.54mm单排8针header（HDR-M_2.54_1x8P），不是已选定的带防反插IDC排线座。位置在板左边；原生pitch2.54mm，8个PTH孔约1.0mm，pin1方pad在上方。

| J2针 | 实际网名 | 待测阵列 |
|---|---|---|
| 1 | ROW0 | 第0行共用端 |
| 2 | ROW1 | 第1行共用端 |
| 3 | ROW2 | 第2行共用端 |
| 4 | ROW3 | 第3行共用端 |
| 5 | COL0 | 第0列共用端 |
| 6 | COL1 | 第1列共用端 |
| 7 | COL2 | 第2列共用端 |
| 8 | COL3 | 第3列共用端 |

每个电阻Rij的一端接ROWi，另一端接COLj。例如R00=J2.1到J2.5，R23=J2.3到J2.8。16个电阻形成4×4行列网络，用这8根共用线接入；不能把它当成16组各自完全独立的两线输入。板上不装这16个外部待测电阻。
J2没有额外供电/GND引脚；不要把其中一根行/列线改接地。行/列不是任意顺序，pin1方向和两端编号必须一致。

若阵列端是单排8针2.54mm母接头，可在确定针截面/壳体后评估直接配对。若是双排IDC成品排线，现有单排J2不能直接插；需要明确阵列端和线缆型号，再选配套板座或明确外部转接。当前没有选定IDC插座，不声称成品排线可用，不自动制造/采购转接。
具体线缆/接头型号、长度、应力释放和针1防反插仍PENDING_INPUT。已在本聊天询问用户实际接口。若确定接口不兼容，再集中提出最小J2接口ECO及后续预算，本包不改PCB；不能为了补接口默许新增CAD。
本接线说明来自当前实际550pad/net记录，不能当作已完成16电阻实物测试、线阻/线缆寄生验证或上电放行。

# 用户明确的待测阵列接口要求

用户在本包交付前补充：“单排8针线 不是那种焊上去的是那种插槽你懂吧”。

落实为：板上采用单排8位可插拔板端连接器，线束通过匹配线端接头插入/拔出；不能以8根导线直接焊在PCB上完成接口。ROW0–ROW3、COL0–COL3映射保持。

现有J2是通用HDR-M_2.54_1x8P排针，尚无成套板座/线端壳体具体厂家MPN。用户已明确单排可插拔需求，不再等待用户确认是否IDC。现有线端的针距、公母/接触结构、壳体方向/锁扣和尺寸仍未提供，不能把“单排8针”冒充特定型号或假定兼容。

本补充是最终只读审查后的用户接口输入，非追加技术复核、CAD或制造操作。原报告中“线材类型待输入”按本补充更新为“单排8位可插拔已明确，具体配套型号/机械尺寸待匹配”。原审查数据/三项Minor和失败记录不改。

下一次正常工程接续应集中选定配套板端/线端方案，按必要最小J2接口ECO申请有界CAD预算，不研究工具，不重布整板。当前16号只读包CAD/采购/制造/上电仍为0，未在本包改J2。
